這是一套專門用來掃描幣安（Binance）合約市場、篩選符合多頭排列（均線多頭）與週期共振標的，並提供互動式多週期圖表（包含 K 線、移動平均線、量能均線及自定義週期虛線）的高效能單檔網頁儀表板。
整個程式分為 HTML 結構、CSS 樣式、JavaScript 核心邏輯、Web Worker 背景多執行緒掃描四大區塊。以下為您詳細拆解其核心運作邏輯與架構：
一、 核心架構與運行流程
 * 資料載入與初始化 (startScan)：
   * 點擊「啟動極速掃描」後，程式會先向幣安期貨 API (/fapi/v1/ticker/24hr) 抓取所有 24 小時的Ticker行情資料。
   * 過濾出計價幣別為 USDT 且 24 小時成交額大於 1 億 USDT 的高流動性標的，作為候選清單。
 * Web Worker 背景平行運算：
   * 為了避免主執行緒（UI 執行緒）介面卡頓，程式動態建立了一個 Web Worker。
   * Worker 內部以 40 個請求為一個並行批次（Concurrency Chunk），同時向幣安 API 抓取各標的在 15m、1h``、4h、1d 四種週期的 K 線資料 (/fapi/v1/klines`)。
 * 多頭排列判定演算法 (isBullishAlignment)：
   * 取得收盤價（Close）陣列後，透過 SMA（簡單移動平均線）演算法計算出 30MA、45MA、60MA。
   * 多頭判定條件：當前最新的價格必須站在 60MA 之上，且三條均線呈現多頭排列（30MA > 45MA > 60MA）。
   * 同時會檢查當根 K 線是否為「剛突破站上三條均線」的瞬間，並計算現價與 60MA 的乖離率。
二、 主要功能模組解析
1. 多分頁切換與清單分類 (tab-container)
掃描完成後，程式會將符合條件的標的依據漲跌幅排序，並分類至不同分頁：
 * ⚡ 15M / 1H / 4H / 1D：分別顯示在該單一週期符合多頭排列的幣種。
 * 🔥 共振：顯示同時滿足兩個或以上週期多頭排列的強勢共振標的。
 * 即時清單互動：點擊任一標的卡片，會觸發 openChartModal() 打開大圖互動視窗。
2. Canvas高效繪圖與多週期對比 (chart-modal)
當彈跳視窗打開時，程式會同步繪製 4 個獨立的 Canvas 面板（分別對應 15m、1h、4h、1d）：
 * 雙重座標軸（主圖 + 量能圖）：
   * 主圖區 (65%)：繪製 K 線本體（紅綠柱）、均線（5MA 綠、30MA 黃、45MA 橘、60MA 粉紅），並在符合突破條件的 K 線上方標記黃色閃電 ⚡。
   * 副圖區 (25%)：繪製成交量柱狀圖，以及成交量均線（5VM 藍色、20VM 紫色）。
 * 動態自適應高解析度 (DPR)：針對 Retina 螢幕進行點陣放大（window.devicePixelRatio），確保圖表在手機與電腦上都極度清晰。
3. 週期直條虛線條件（您的最新需求）
在 Canvas 繪圖迴圈中，程式會依據每一根 K 線的時間戳記（Timestamp）與當前圖表週期，精準計算並繪製垂直虛線：
 * 日週期 (1D)：以 1 週區間（每週一 00:00 UTC）畫一條垂直虛線。
 * 4小時 (4H)：以 1 日區間（每日 00:00 UTC）畫一條垂直虛線。
 * 1小時 (1H)：以 4 小時區間（每 4 小時整點，如 00、04、08...）畫一條垂直虛線。
 * 15分 (15M)：以 1 小時區間（每小時整點）畫一條垂直虛線。
三、 互動體驗與行動端優化
 * 左右滑動切換標的 (handleSwipe)：在手機或觸控板上，支援左右滑動手勢直接切換上一隻/下一隻幣種的圖表。
 * 鍵盤快捷鍵：支援電腦鍵盤操作（Esc 關閉視窗、← / → 切換幣種）。
 * 響應式排版：採用 CSS Grid 與 Flexbox，完美適應各種手機螢幕尺寸與電腦桌面，並在手機端自動鎖定背景滾動 (modal-open)，提供流暢的 App 級操作體驗。
