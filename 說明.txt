這份**「多週期多頭排列儀表板 (>1億USDT)」**程式碼採用了現代的 HTML5 Canvas 技術與 Binance Futures API，專門用來過濾並即時檢視加密貨幣的技術指標。
整個程式的架構與核心邏輯可以拆解為以下幾個主要模組：
一、 核心設計與全域常數
 * 資料來源與過濾條件：串接幣安期貨 (fapi.binance.com) 的 API。透過 24 小時行情 (/fapi/v1/ticker/24hr) 過濾出每日成交額大於 1 億 USDT (MIN_VOLUME = 100000000) 的主流標的。
 * 均線參數：設定了短中長期均線：
   * P0 = 5（短期 5MA）
   * P1 = 30（30MA）
   * P2 = 45（45MA）
   * P3 = 60（長期 60MA）
 * 非同步併發控制 (batchProcess)：為了避免一次送出幾百個 API 請求造成瀏覽器卡死或被幣安限流，程式設定了併發上限（CONCURRENCY_LIMIT = 15），分批次平順、極速地抓取各大幣種的 K 線資料。
二、 多頭排列與訊號判定邏輯 (isBullishAlignment)
這是儀表板的靈魂，用來篩選符合多頭條件的幣種：
 * 均線多頭排列（發散）：
   檢查最後一根收盤時，30\text{MA} > 45\text{MA} > 60\text{MA}（即 P1 > P2 > P3），且當前價格大於等於長均線（price \ge 60\text{MA}）。
 * 多頭全站上檢測 (checkAboveAllMAsAtIndex)：
   嚴格檢查當前收盤價是否同時站上所有均線（價格 \ge 5\text{MA}、 30\text{MA}、 45\text{MA}、 60\text{MA}）。
 * 閃電突破訊號 (⚡)：
   比對「這一根 K 棒」與「前一根 K 棒」的狀態：若前一根還沒完全站上所有均線，但這一根「剛好站上」，就會被判定為突破瞬間，並在 K 棒上方標上醒目的閃電符號 (⚡)。
 * 週期共振：
   程式會分別計算 15m、1h、4h 三個時間框架。如果一個幣種在多個框架同時符合多頭，就會被歸類為「共振標的」（\ge 2 個週期符合），並在列表與卡片上打上特殊的熱門標籤。
三、 Canvas 高效繪圖與互動圖表引擎
為了讓使用者點擊卡片時能「秒開」3 個時間框架的走勢圖（15M、1H、4H），程式放棄了肥大的第三方圖表庫，改用原生的 HTML5 Canvas 自行刻畫：
 * 高解析度適配 (Retina / DPR)：
   程式會自動抓取 window.devicePixelRatio，對 Canvas 進行點陣縮放與 CSS 尺寸校正，確保在手機或電腦的高畫質螢幕上線條與字體都極為銳利清晰。
 * 雙層畫面排版（價格區 + 成交量區）：
   * 上方價格區（佔 62%）：繪製主 K 線（紅綠柱體）、均線（5MA 綠色、30MA 黃色、45MA 橙色、60MA 粉紅），以及動態計算的最高/最低價網格。
   * 下方成交量區（佔 28%）：繪製成交量柱狀圖，以及成交量均線（5VM 亮青色、10VM 紫色）。
 * 亮麗成交量反轉提示（⭐ 閃爍星星）：
   在成交量均線（5VM）的邏輯中，當發現 5VM 呈現「由跌轉升」（當前大於前一根，且前一根小於等於前兩根）的轉折點時，會在該根成交量上方繪製剛升級完成的極亮螢光黃星星 (#ffff00)，並帶有強烈的發光暈染特效（shadowBlur: 10），讓量能反轉點一目了然。
四、 UI 互動與響應式體驗
 * 多頁籤切換：頂部的頁籤可一鍵切換檢視「15M多頭」、「1H多頭」、「4H多頭」以及「多週期共振」。
 * 彈窗燈箱與單獨放大 (maximizedPeriod)：
   * 點擊任一幣種卡片會彈出 3 圖表視窗。
   * 點擊圖表中的任一個時間區塊（例如 15M），該區塊會瞬間最大化佔滿整個畫面，方便深入觀察；再次點擊則會恢復三圖並排。
 * 行動端手勢與鍵盤支援：
   * 支援手機左右滑動（Swipe）切換不同幣種。
   * 支援電腦鍵盤的 Esc 關閉彈窗，以及 ← / → 鍵快速切換上一個或下一個幣種。
