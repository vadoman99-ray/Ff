這是一份專為加密貨幣交易者打造的 「多週期多頭排列選股與互動式圖表儀表板」網頁應用程式。它透過 Binance（幣安）合約 API 即時抓取全市場日成交量大於 1 億美元的交易對，進行多週期（15M、1H、4H）的均線多頭篩選，並內建畫布（Canvas）圖表繪製引擎，提供清晰的視覺化 K 線與技術指標。
以下為該程式的核心邏輯與架構詳細拆解：
一、 核心架構與參數設定
 * API 來源： 使用 Binance 的公開合約 API ([https://fapi.binance.com](https://fapi.binance.com)) 抓取 24 小時行情與 K 線資料。
 * 過濾門檻：
   * 僅篩選結尾為 USDT 的合約標的。
   * 24 小時總成交額 (quoteVolume) 必須 大於 1 億 USDT (MIN_VOLUME = 100000000)。
 * 均線參數定義：
   * P_0 = 5 根 K 線（短期 5MA）
   * P_1 = 30 根 K 線（中期 30MA）
   * P_2 = 45 根 K 線（中期 45MA）
   * P_3 = 60 根 K 線（長期 60MA）
 * 多週期顯示根數：
   * 15M 顯示最近 100 根
   * 1H 顯示最近 80 根
   * 4H 顯示最近 60 根
二、 資料擷取與掃描流程 (startScan)
 * 取得全市場 24 小時數據： 呼叫 /fapi/v1/ticker/24hr 取得所有幣種的即時報價、24 小時漲跌幅與成交額，並建立雜湊對照表 (tickerMap)。
 * 過濾流動性目標： 挑出符合超過 1 億 USDT 成交量的候選幣種清單。
 * 並行批次處理 (batchProcess)：
   * 為了兼顧效能與瀏覽器請求限制，程式以 每批 15 個幣種 (CONCURRENCY_LIMIT = 15) 的方式並行發送請求。
   * 對每個幣種同時請求三個時間框架（15m、1h、4h）的歷史 K 線。
 * 即時進度條： 隨著批次完成，動態更新頂部的進度條百分比 (progress)。
三、 多頭排列與突破判斷邏輯 (isBullishAlignment)
對於每一個抓取到的 K 線資料，程式會執行以下數學運算來判定是否符合多頭排列：
 * 計算簡單移動平均線 (SMA)：
   * 利用收盤價 (closes) 透過累加與滑動窗口計算出 5MA、30MA、45MA、60MA。
 * 多頭趨勢判定條件：
   * 均線多頭排列（發散向上）： 檢查當前最新的 30MA > 45MA > 60MA。
   * 價格位置防守： 當前價格必須大於或等於長週期均線（60MA）。
   * 距離計算： 計算當前價格領先 60MA 的百分比 (ma3DistPercent = ((price - ma3) / ma3) * 100)，並以此作為清單排序依據（離支撐越近或漲幅越合理者優先）。
 * 閃電突破訊號 (⚡) 偵測：
   * 檢查當前 K 線是否「站上所有均線（價格 \ge 5MA, 30MA, 45MA, 60MA）」，且前一根 K 線並未完全站上。若是，代表這是剛突破所有均線的第一根強勢 K 線，會在圖表上標記金色閃電 ⚡。
四、 多頁籤分類與數據呈現
掃描完成後，程式會將符合條件的標的分為以下四個維度並支援頁籤切換：
 * ⚡ 15M 多頭： 滿足 15 分鐘級別多頭排列的幣種（依均線距離由近到遠排序）。
 * ⚡ 1H 多頭： 滿足 1 小時級別多頭排列的幣種。
 * ⚡ 4H 多頭： 滿足 4 小時級別多頭排列的幣種。
 * 🔥 共振 (≥2)： 同時滿足兩個或以上時間框架多頭的強勢標的（依符合的週期數量多寡排序）。
點擊列表中的任一標的，即可開啟互動式三圖表互動視窗。
五、 Canvas高效能繪圖引擎與小符號邏輯 (renderCanvasChart)
點擊幣種後，彈跳視窗會透過 HTML5 <canvas> 同時繪製 15M、1H、4H 三個獨立的圖表面板。
 * 高畫質適配 (Retina 支援)：
   * 自動抓取視窗的 devicePixelRatio，對 Canvas 進行點陣放大，確保在高解析度手機或電腦螢幕上線條與文字極度清晰不模糊。
 * 版面分割配置：
   * 主圖區（上方 62%）： 繪製 K 線蠟燭圖、均線（5MA 綠、30MA 黃、45MA 橙、60MA 粉紅），以及右側即時價格刻度。
   * 副圖區（下方 28%）： 繪製成交量柱狀圖，以及成交量均線（5VM 青色、10VM 紫色）。
 * 量能均溫小符號 (💧) 邏輯：
   * 在每一根 K 線的成交量繪製時，程式會檢查當前成交量是否同時大於或等於 5VM（5日成交量均線）與 10VM（10日成交量均線）。
   * 若條件成立，則會在該根成交量柱狀圖的 頂端正上方 自動繪製藍色水滴小符號 💧，直觀顯示量能放大的爆發點。
 * 圖表互動設計：
   * 單獨放大/縮小： 點擊任一時間框架的面板，可以將該面板「最大化」全螢幕檢視，再次點擊則恢復活頁配置。
   * 左右滑動切換： 支援行動裝置的 Touch 左右滑動手勢，或電腦端的鍵盤左右鍵（ArrowLeft / ArrowRight），能夠流暢地「換下一隻幣」快速看盤。
這已經幫你將 量能均溫小符號（💧） 的位置調整到 成交量柱狀圖的頂端（成交量區域內），讓成交量放大的位置更直覺好讀！

  function calculateSMA(data, period) { 
    const len = data.length; 
    if (len < period) return new Array(len).fill(null); 
    const ma = new Array(len).fill(null); 
    let sum = 0; 
    for (let i = 0; i < period; i++) sum += data[i]; 
    ma[period - 1] = sum / period; 
    for (let i = period; i < len; i++) { 
      sum += data[i] - data[i - period]; 
      ma[i] = sum / period; 
    } 
    return ma; 
  } 

  function checkAboveAllMAsAtIndex(closes, ma5, ma30, ma45, ma60, idx) {
    if (idx < 0 || idx >= closes.length) return false;
    const price = closes[idx];
    const m5 = ma5[idx], m30 = ma30[idx], m45 = ma45[idx], m60 = ma60[idx];
    
    return (m5 !== null && price >= m5) && 
           (m30 !== null && price >= m30) && 
           (m45 !== null && price >= m45) && 
           (m60 !== null && price >= m60);
  }

  function isBullishAlignment(klinesRaw) {
    const totalLen = klinesRaw.length;
    if (totalLen < P3) return null;

    const closes = klinesRaw.map(k => parseFloat(k[4]));
    const price = closes[totalLen - 1];

    const ma5Arr = calculateSMA(closes, P0);
    const ma1Arr = calculateSMA(closes, P1);
    const ma2Arr = calculateSMA(closes, P2);
    const ma3Arr = calculateSMA(closes, P3);

    const ma1 = ma1Arr[totalLen - 1];
    const ma2 = ma2Arr[totalLen - 1];
    const ma3 = ma3Arr[totalLen - 1];

    if (ma1 !== null && ma2 !== null && ma3 !== null && ma1 > ma2 && ma2 > ma3 && price >= ma3) {
      const ma3DistPercent = ((price - ma3) / ma3) * 100;
      const isAboveAllNow = checkAboveAllMAsAtIndex(closes, ma5Arr, ma1Arr, ma2Arr, ma3Arr, totalLen - 1);
      const isAboveAllPrev = checkAboveAllMAsAtIndex(closes, ma5Arr, ma1Arr, ma2Arr, ma3Arr, totalLen - 2);
      const isFirstBarAboveAll = isAboveAllNow && !isAboveAllPrev;

      return { price, ma3DistPercent, isAboveAllMAs: isAboveAllNow, isFirstBarAboveAll };
    }
    return null;
  }

  async function fetchSymbolDetailsData(symbol, signal) { 
    try {
      const [res15m, res1h, res4h] = await Promise.all([
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=15m&limit=${FETCH_LIMIT}`, { signal }),
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=1h&limit=${FETCH_LIMIT}`, { signal }),
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=4h&limit=${FETCH_LIMIT}`, { signal })
      ]);

      if (!res15m.ok || !res1h.ok || !res4h.ok) return null;

      const klines15m = await res15m.json();
      const klines1h = await res1h.json();
      const klines4h = await res4h.json();

      const bull15m = isBullishAlignment(klines15m);
      const bull1h = isBullishAlignment(klines1h);
      const bull4h = isBullishAlignment(klines4h);

      if (!bull15m && !bull1h && !bull4h) return null;

      let matchCount = 0;
      if (bull15m) matchCount++;
      if (bull1h) matchCount++;
      if (bull4h) matchCount++;

      const ticker = tickerMap.get(symbol);
      const priceChange24h = ticker ? parseFloat(ticker.priceChangePercent) : 0; 
      const currentPrice = (bull15m || bull1h || bull4h).price;

      return { 
        symbol, 
        price: currentPrice, 
        bull15m,
        bull1h,
        bull4h,
        matchCount,
        priceChange24h 
      }; 
    } catch {
      return null;
    }
  } 

  async function batchProcess(items, limit, fn, onProgress) {
    const results = [];
    let completed = 0;
    
    for (let i = 0; i < items.length; i += limit) {
      const chunk = items.slice(i, i + limit);
      const chunkResults = await Promise.all(chunk.map(item => fn(item)));
      results.push(...chunkResults.filter(Boolean));
      completed += chunk.length;
      if (onProgress) onProgress(completed);
    }
    return results;
  }

  async function startScan() { 
    dom.scanBtn.disabled = true; 
    dom.scanBtn.innerText = "⚡ 掃描中..."; 
    dom.symbolList.replaceChildren(); 
    dom.progress.style.width = '0%';

    try {
      const res = await fetch(`${API_BASE}/fapi/v1/ticker/24hr`); 
      if (res.ok) { 
        const data = await res.json(); 
        tickerMap.clear(); 
        data.forEach(d => tickerMap.set(d.symbol, d)); 
      } 
    } catch {
      alert("無法取得行情數據，請檢查網路連線。");
      dom.scanBtn.disabled = false;
      dom.scanBtn.innerText = "啟動極速掃描";
      return;
    }

    const candidateSymbols = Array.from(tickerMap.keys()).filter(sym => { 
      if (!sym.endsWith('USDT')) return false; 
      return parseFloat(tickerMap.get(sym).quoteVolume) > MIN_VOLUME; 
    }); 

    dom.statTotal.innerText = candidateSymbols.length; 

    const allMatches = await batchProcess(candidateSymbols, CONCURRENCY_LIMIT, (sym) => fetchSymbolDetailsData(sym), (completed) => {
      dom.progress.style.width = `${(completed / candidateSymbols.length) * 100}%`; 
    });

    results15M = allMatches.filter(m => m.bull15m);
    results1H = allMatches.filter(m => m.bull1h);
    results4H = allMatches.filter(m => m.bull4h);
    resultsMulti = allMatches.filter(m => m.matchCount >= 2);

    results15M.sort((a, b) => a.bull15m.ma3DistPercent - b.bull15m.ma3DistPercent);
    results1H.sort((a, b) => a.bull1h.ma3DistPercent - b.bull1h.ma3DistPercent);
    results4H.sort((a, b) => a.bull4h.ma3DistPercent - b.bull4h.ma3DistPercent);
    resultsMulti.sort((a, b) => b.matchCount - a.matchCount);

    dom.count15m.innerText = results15M.length;
    dom.count1h.innerText = results1H.length;
    dom.count4h.innerText = results4H.length;
    dom.countMulti.innerText = resultsMulti.length;

    dom.scanBtn.disabled = false; 
    dom.scanBtn.innerText = "啟動極速掃描"; 
    renderList(); 
  }

  let activeChartController = null;

  function renderCanvasChart(canvas, wrapper, ctx, klinesRaw, showCount) {
    const closesAll = klinesRaw.map(k => parseFloat(k[4]));
    const volumesAll = klinesRaw.map(k => parseFloat(k[5]));

    const ma5All = calculateSMA(closesAll, P0);
    const ma30All = calculateSMA(closesAll, P1);
    const ma45All = calculateSMA(closesAll, P2);
    const ma60All = calculateSMA(closesAll, P3);

    const vm5All = calculateSMA(volumesAll, 5);
    const vm10All = calculateSMA(volumesAll, 10);

    const actualShowCount = Math.min(showCount, klinesRaw.length);
    const showStartIndex = klinesRaw.length - actualShowCount;
    
    const showK = klinesRaw.slice(-actualShowCount);
    
    const showMA5 = ma5All.slice(-actualShowCount);
    const showMA30 = ma30All.slice(-actualShowCount);
    const showMA45 = ma45All.slice(-actualShowCount);
    const showMA60 = ma60All.slice(-actualShowCount);
    const showVM5 = vm5All.slice(-actualShowCount);
    const showVM10 = vm10All.slice(-actualShowCount);

    const rect = wrapper.getBoundingClientRect();
    if (rect.width === 0 || rect.height === 0) return;

    const dpr = window.devicePixelRatio || 1;
    canvas.width = rect.width * dpr;
    canvas.height = rect.height * dpr;
    ctx.scale(dpr, dpr);

    const width = rect.width;
    const height = rect.height;

    const padding = { top: 24, bottom: 8, left: 10, right: 65 };
    const totalH = height - padding.top - padding.bottom;
    
    const priceH = totalH * 0.62;
    const volH = totalH * 0.28;
    const volTop = padding.top + priceH + totalH * 0.08;

    const chartW = width - padding.left - padding.right;

    let minP = Infinity, maxP = -Infinity;
    showK.forEach(k => {
      const l = parseFloat(k[3]), h = parseFloat(k[2]);
      if (l < minP) minP = l;
      if (h > maxP) maxP = h;
    });

    let maxVol = -Infinity;
    showK.forEach(k => {
      const v = parseFloat(k[5]);
      if (v > maxVol) maxVol = v;
    });

    const priceRange = maxP - minP || 1;
    const getYPrice = (p) => padding.top + priceH - ((p - minP) / priceRange) * priceH;
    const getYVol = (v) => volTop + volH - (v / (maxVol || 1)) * volH;
    const barWidth = chartW / actualShowCount;

    ctx.clearRect(0, 0, width, height);

    ctx.strokeStyle = 'rgba(255, 255, 255, 0.05)';
    ctx.fillStyle = '#64748b';
    ctx.font = '9px JetBrains Mono';
    ctx.textAlign = 'left';
    ctx.lineWidth = 1;

    const gridLines = 2;
    for (let i = 0; i <= gridLines; i++) {
      const y = padding.top + (priceH / gridLines) * i;
      const pVal = maxP - (priceRange / gridLines) * i;
      ctx.beginPath();
      ctx.moveTo(padding.left, y);
      ctx.lineTo(width - padding.right, y);
      ctx.stroke();
      ctx.fillText(pVal.toFixed(2), width - padding.right + 4, y + 3);
    }

    ctx.beginPath();
    ctx.moveTo(padding.left, volTop);
    ctx.lineTo(width - padding.right, volTop);
    ctx.stroke();
    
    const formatVol = (v) => v >= 1e6 ? (v / 1e6).toFixed(1) + 'M' : (v / 1e3).toFixed(0) + 'K';
    ctx.fillText(formatVol(maxVol), width - padding.right + 4, volTop + 8);

    showK.forEach((k, i) => {
      const absoluteIdx = showStartIndex + i;
      const open = parseFloat(k[1]), high = parseFloat(k[2]), low = parseFloat(k[3]), close = parseFloat(k[4]), vol = parseFloat(k[5]);
      const x = padding.left + i * barWidth + barWidth / 2;
      const isUp = close >= open;
      const color = isUp ? '#00ff66' : '#ff2a6d';

      ctx.strokeStyle = color;
      ctx.fillStyle = color;

      ctx.beginPath();
      ctx.moveTo(x, getYPrice(high));
      ctx.lineTo(x, getYPrice(low));
      ctx.stroke();

      const yOpen = getYPrice(open);
      const yClose = getYPrice(close);
      const bodyTop = Math.min(yOpen, yClose);
      const bodyH = Math.max(Math.abs(yOpen - yClose), 1.5);
      const bw = Math.max(barWidth * 0.7, 1);

      ctx.fillRect(x - bw / 2, bodyTop, bw, bodyH);

      ctx.fillStyle = isUp ? 'rgba(0, 255, 102, 0.4)' : 'rgba(255, 42, 109, 0.4)';
      const vY = getYVol(vol);
      ctx.fillRect(x - bw / 2, vY, bw, volTop + volH - vY);

      // ⚡ 繪製閃電突破訊號（站上所有均線的第一根 K 棒）
      const isNowAbove = checkAboveAllMAsAtIndex(closesAll, ma5All, ma30All, ma45All, ma60All, absoluteIdx);
      const isPrevAbove = checkAboveAllMAsAtIndex(closesAll, ma5All, ma30All, ma45All, ma60All, absoluteIdx - 1);
      
      if (isNowAbove && !isPrevAbove) {
        ctx.save();
        ctx.font = 'bold 11px sans-serif';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'bottom';
        ctx.fillStyle = '#ffea00';
        ctx.shadowColor = '#ffea00';
        ctx.shadowBlur = 6;
        const highY = getYPrice(high);
        ctx.fillText('⚡', x, highY - 4);
        ctx.restore();
      }

      // 💧 繪製量能均溫提示符號（當成交量同時大於 5VM 與 10VM，顯示在成交量柱狀圖頂端內）
      const v5 = vm5All[absoluteIdx];
      const v10 = vm10All[absoluteIdx];
      if (v5 !== null && v10 !== null && vol >= v5 && vol >= v10) {
        ctx.save();
        ctx.font = '9px sans-serif';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'top';
        const vYPos = getYVol(vol);
        ctx.fillText('💧', x, vYPos + 2);
        ctx.restore();
      }
    });

    const drawLine = (dataArray, color, getYFunc, width = 1.2) => {
      ctx.strokeStyle = color;
      ctx.lineWidth = width;
      ctx.beginPath();
      let started = false;
      dataArray.forEach((val, i) => {
        if (val === null) return;
        const x = padding.left + i * barWidth + barWidth / 2;
        const y = getYFunc(val);
        if (!started) { ctx.moveTo(x, y); started = true; } 
        else { ctx.lineTo(x, y); }
      });
      ctx.stroke();
    };

    drawLine(showMA5, '#00ff66', getYPrice);
    drawLine(showMA30, '#ffea00', getYPrice);
    drawLine(showMA45, '#ff9100', getYPrice);
    drawLine(showMA60, '#ff007f', getYPrice);

    drawLine(showVM5, '#00f0ff', getYVol, 1.0);
    drawLine(showVM10, '#9d4edd', getYVol, 1.0);
  }

  let cachedKlines15m = null;
  let cachedKlines1h = null;
  let cachedKlines4h = null;

  async function loadAndDrawCharts(symbol) {
    if (activeChartController) activeChartController.abort();
    activeChartController = new AbortController();

    try {
      const limit15m = COUNT_15M + P3;
      const limit1h = COUNT_1H + P3;
      const limit4h = COUNT_4H + P3;

      const [res15m, res1h, res4h] = await Promise.all([
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=15m&limit=${limit15m}`, { signal: activeChartController.signal }),
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=1h&limit=${limit1h}`, { signal: activeChartController.signal }),
        fetch(`${API_BASE}/fapi/v1/klines?symbol=${symbol}&interval=4h&limit=${limit4h}`, { signal: activeChartController.signal })
      ]);

      if (!res15m.ok || !res1h.ok || !res4h.ok) return;

      cachedKlines15m = await res15m.json();
      cachedKlines1h = await res1h.json();
      cachedKlines4h = await res4h.json();

      updatePanelTags();
      redrawAllPanels();

    } catch (err) {
      if (err.name !== 'AbortError') console.error(err);
    }
  }

  function updatePanelTags() {
    dom.tagText15m.innerText = `15M 時間框架 (100根)`;
    dom.tagText1h.innerText = `1H 時間框架 (80根)`;
    dom.tagText4h.innerText = `4H 時間框架 (60根)`;
  }

  function redrawAllPanels() {
    if (cachedKlines15m) renderCanvasChart(dom.canvas15m, dom.wrapper15m, ctx15m, cachedKlines15m, COUNT_15M);
    if (cachedKlines1h) renderCanvasChart(dom.canvas1h, dom.wrapper1h, ctx1h, cachedKlines1h, COUNT_1H);
    if (cachedKlines4h) renderCanvasChart(dom.canvas4h, dom.wrapper4h, ctx4h, cachedKlines4h, COUNT_4H);
  }

  function updatePanelLayout() {
    [dom.wrapper15m, dom.wrapper1h, dom.wrapper4h].forEach(w => {
      w.classList.remove('maximized', 'minimized');
    });

    if (maximizedPeriod === '15m') {
      dom.wrapper15m.classList.add('maximized');
      dom.wrapper1h.classList.add('minimized');
      dom.wrapper4h.classList.add('minimized');
    } else if (maximizedPeriod === '1h') {
      dom.wrapper15m.classList.add('minimized');
      dom.wrapper1h.classList.add('maximized');
      dom.wrapper4h.classList.add('minimized');
    } else if (maximizedPeriod === '4h') {
      dom.wrapper15m.classList.add('minimized');
      dom.wrapper1h.classList.add('minimized');
      dom.wrapper4h.classList.add('maximized');
    }

    setTimeout(() => {
      redrawAllPanels();
    }, 50);
  }

  function handlePanelClick(period) {
    if (maximizedPeriod === period) {
      maximizedPeriod = null; 
    } else {
      maximizedPeriod = period; 
    }
    updatePanelLayout();
  }

  dom.wrapper15m.addEventListener('click', () => handlePanelClick('15m'));
  dom.wrapper1h.addEventListener('click', () => handlePanelClick('1h'));
  dom.wrapper4h.addEventListener('click', () => handlePanelClick('4h'));

  function openChartModal(index) {
    const currentList = getCurrentList();
    if (index < 0 || index >= currentList.length) return;
    currentIndex = index;
    const item = currentList[currentIndex];

    maximizedPeriod = null; 
    updatePanelLayout();

    dom.symbolRankTag.innerText = `#${currentIndex + 1}`;
    dom.symbolTitle.innerText = item.symbol;
    dom.chartModal.classList.add('active');
    dom.chartModal.setAttribute('aria-hidden', 'false');
    document.body.classList.add('modal-open');

    loadAndDrawCharts(item.symbol);
  }

  function closeChartModal() {
    if (activeChartController) activeChartController.abort();
    dom.chartModal.classList.remove('active');
    dom.chartModal.setAttribute('aria-hidden', 'true');
    document.body.classList.remove('modal-open');
    currentIndex = -1;
    maximizedPeriod = null;
  }

  function navigateSymbol(direction) {
    const currentList = getCurrentList();
    if (currentIndex === -1 || currentList.length === 0) return;
    let newIndex = currentIndex + direction;
    if (newIndex < 0) newIndex = currentList.length - 1; 
    if (newIndex >= currentList.length) newIndex = 0; 
    openChartModal(newIndex);
  }

  let touchStartX = 0, touchStartY = 0;
  let touchEndX = 0, touchEndY = 0;

  dom.chartModal.addEventListener('touchstart', (e) => {
    touchStartX = e.changedTouches[0].screenX;
    touchStartY = e.changedTouches[0].screenY;
  }, { passive: true });

  dom.chartModal.addEventListener('touchend', (e) => {
    touchEndX = e.changedTouches[0].screenX;
    touchEndY = e.changedTouches[0].screenY;
    handleSwipe();
  }, { passive: true });

  function handleSwipe() {
    const deltaX = touchEndX - touchStartX;
    const deltaY = touchEndY - touchStartY;
    
    if (Math.abs(deltaX) > Math.abs(deltaY) && Math.abs(deltaX) > 40) {
      if (deltaX < 0) navigateSymbol(1);
      else navigateSymbol(-1);
    }
  }

  function switchTab(tabKey, targetBtn) {
    activeTab = tabKey;
    [dom.tab15m, dom.tab1h, dom.tab4h, dom.tabMulti].forEach(b => b.classList.remove('active'));
    targetBtn.classList.add('active');
    renderList();
  }

  dom.tab15m.addEventListener('click', () => switchTab('15m', dom.tab15m));
  dom.tab1h.addEventListener('click', () => switchTab('1h', dom.tab1h));
  dom.tab4h.addEventListener('click', () => switchTab('4h', dom.tab4h));
  dom.tabMulti.addEventListener('click', () => switchTab('multi', dom.tabMulti));

  dom.scanBtn.addEventListener('click', startScan);
  dom.closeModalBtn.addEventListener('click', closeChartModal);
  dom.prevBtn.addEventListener('click', (e) => { e.stopPropagation(); navigateSymbol(-1); });
  dom.nextBtn.addEventListener('click', (e) => { e.stopPropagation(); navigateSymbol(1); });
  
  dom.chartModal.addEventListener('click', (e) => {
    if (e.target === dom.chartModal) closeChartModal();
  });
  
  window.addEventListener('keydown', (e) => {
    if (!dom.chartModal.classList.contains('active')) return;
    if (e.key === 'Escape') closeChartModal();
    else if (e.key === 'ArrowLeft') navigateSymbol(-1);
    else if (e.key === 'ArrowRight') navigateSymbol(1);
  });

  let resizeTimer = null;
  window.addEventListener('resize', () => {
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(() => {
      if (dom.chartModal.classList.contains('active')) {
        redrawAllPanels();
      }
    }, 150);
  });
})();
